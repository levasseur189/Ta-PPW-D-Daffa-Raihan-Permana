# 🌐 TechNova — Landing Page Perusahaan Teknologi

TechNova adalah landing page modern dan responsif untuk perusahaan startup teknologi yang berfokus pada pengembangan **Perangkat Lunak, Web Apps, Mobile Apps**, serta **Solusi IT**.  
Website ini dibangun menggunakan **Tailwind CSS**, dengan desain bertema **biru futuristik** untuk mencerminkan inovasi dan kemajuan teknologi.

## ✨ Fitur Utama

- 🌙 **Desain Modern & Responsif** — tampil optimal di desktop, tablet, dan mobile.  
- 💠 **Warna Biru Futuristik** — memberi kesan profesional dan teknologi maju.  
- 🧭 **Navigasi Dinamis** — header tetap (sticky) dengan menu responsif.  
- 💬 **Hero Section Menarik** — headline, subtitle, dan CTA button interaktif.  
- ⚙️ **Features Section** — menampilkan 3 fitur utama perusahaan.  
- 👥 **About Section** — deskripsi perusahaan dan foto tim.  
- 📩 **Contact Form** — form kontak siap dikembangkan untuk integrasi backend.  
- 🔗 **Footer Elegan** — dengan tautan media sosial dan hak cipta.

## Instalasi

1. **Clone atau Download Repository**
   - Download folder `TA-3-PPW` ke komputer Anda.

2. **Pastikan File Berikut Ada**
   - `index.html` (file utama website)
   - `README.md` (file ini)
   - `bg.avif`
   - `logo.png` 
   - (Opsional) `styles.css` jika ingin menambah custom CSS

3. **Tidak Perlu Instalasi Khusus**
   - Website ini hanya membutuhkan browser modern (Chrome, Firefox, Edge, Safari)
   - Tailwind CSS sudah di-load via CDN di dalam `index.html`

## Cara Penggunaan

1. **Buka Website**
   - Klik dua kali `index.html` atau buka dengan browser favorit Anda.

2. **Navigasi**
   - Gunakan menu di header atau sidebar (mobile) untuk berpindah antar section.
   - Klik tombol di footer untuk kembali ke atas (hero section).

3. **Form Kontak**
   - Isi form kontak untuk mengirim pesan ke tim technova.

4. **Customisasi**
   - Untuk mengubah konten, edit langsung file `index.html`.
   - Untuk menambah style, tambahkan di `styles.css` (jika ada).
